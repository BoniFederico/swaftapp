# User guide

A task-by-task walkthrough of Swaft. If you are new, read
[Core concepts](../concepts.md) first — it defines the vocabulary these pages assume.

| Page | You'll learn to |
|------|-----------------|
| [Workspaces](workspaces.md) | Create local or Git workspaces, encrypt them, and use Git version control. |
| [The Working Tree](working-tree.md) | Organize work with projects, folders, tags and templates. |
| [Document templates](document-templates.md) | Author Seebo documents, use input widgets, and render every subtype. |
| [API requests](api-requests.md) | Build structured HTTP requests with auth, formulas, history and automation. |
| [Code & actions](code-and-actions.md) | Write sandboxed capabilities and actions, confirm effects, and read receipts. |
| [Scenarios](scenarios.md) | Chain requests, actions and capabilities into a visual, runnable workflow. |
| [Environments](environments.md) | Define variable sets and switch the active environment. |
| [Batcher & releases](batcher-and-releases.md) | Render many documents at once and version templates with releases. |
| [Security & settings](security-and-settings.md) | Manage secrets, restrictions, encryption and the execution sandbox. |
