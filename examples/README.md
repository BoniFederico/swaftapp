# Examples

## `demo-workspace/` — "Swaft demo"

A small, ready-to-open Swaft workspace for trying the app. It is a **folder-backed local workspace**:
plain, readable files in the format described in [workspace format reference](../docs/reference/workspace-format.md).

### Open it

1. Start Swaft.
2. On the Homepage choose **Open → From folder**.
3. Select the `examples/demo-workspace` folder.
4. In the Working Tree, open the **Project** selector and pick **Getting started**.

Opening the folder directly edits these files. To experiment without touching the repository copy,
copy the folder somewhere else first and open the copy.

### What's inside

One project, **Getting started**, with four folders and a `demo` tag:

| Folder | Template | Type | What it shows |
|--------|----------|------|---------------|
| Documents | **Welcome letter** | document (markdown) | Seebo formulas with two inputs (`textbox` name, `listbox` plan) and data from `template('company')`. Has a release, `v1`. |
| Documents | **company** | document (json) | Shared JSON data read by other templates through `template('company')`. |
| HTTP | **Get echo** | api (GET) | `${ env('BASE_URL') }/get?name=…` against httpbin.org. |
| HTTP | **Post echo** | api (POST) | Sends a JSON body built from the same inputs. |
| Code | **greeting** | capability (JavaScript) | A custom capability, callable as `${ greeting({ id: 'g', who: 'Ada' }).text }`. |
| Scenarios | **Echo flow** | scenario | Start → Get echo → decision `previous('echo').status == 200` → Post echo → Welcome letter (the false branch waits 1 s). |

It also has one shared environment, **Public echo**, with `BASE_URL=https://httpbin.org`.

### Before you send requests

Which environment is active is stored only on your machine, so a freshly opened copy has none
selected. Pick **Public echo** in the environment picker before you run **Get echo**, **Post echo**
or **Echo flow**. The HTTP requests call the public service at https://httpbin.org, so they need
internet access.

### Regenerating

The workspace is generated by the app's own services, so its on-disk format is always valid:

```sh
SWAFT_WRITE_DEMO=1 npx vitest run apps/desktop/src/main/workspace/demo-workspace.test.ts
```

Without `SWAFT_WRITE_DEMO`, the same test file (part of `npm test`) opens a temporary copy and checks
that the content loads and renders.
